# Pi-Face Ad Blocker Pi-hole API interface

Simple script that allows me to query my local pi-hole instance from my local network.

## Usage

```bash
% python .

usage: . [-h] [--enable] [--disable] [--status] [--stats]

Pi-Face Ad Blocker Pi-hole API interface

options:
  -h, --help  show this help message and exit
  --enable    Enable Pi-hole blocking
  --disable   Disable Pi-hole blocking
  --status    Get the status of Pi-hole
  --stats     Get all the stats of Pi-hole


PiFace is enabled
```
